# 上架粘贴包 · 使用说明

把这一整套东西拿去淘宝「发布商品」后台手动粘贴即可。核心是文案 + 实机截图，浏览器能不能连都能用。

## 文件夹里有什么

| 文件 | 用途 |
| --- | --- |
| `上架文案.md` | 标题、类目、价格建议、卖点、详情正文、FAQ、购买须知，全部可直接复制 |
| `主图-1.png` | 主图第 1 张：整体中文界面实机截图 |
| `主图-2.png` | 主图第 2 张：生成 / 材质参数面板中文效果 |
| `主图-3.png` | 主图第 3 张：右键菜单中文效果 |
| `主图-4.png` | 主图第 4 张：卖点文字卡（纯显示层汉化、中英切换、自动适配） |
| `详情长图.png` | 一张 750px 宽的详情竖长图（标题 + 卖点 + 三张实机截图 + 收尾） |
| `detail-images/` | 三张用于详情页的单张实机截图（`01-overview`、`02-panel-params`、`03-panel-menu`） |

## 怎么上传

### 主图区（5 张主图位）
按顺序传「主图-1 ~ 主图-4」，若还差一张可再补一张实机截图。

### 图文详情
两种方式任选：

**方式 A（最省事）**：直接上传整张 `详情长图.png`，把上面的标题、卖点、三张实机截图一次带齐。

**方式 B（想配文字）**：
1. 文字区粘贴 `上架文案.md` 里「详情页正文」的内容；
2. 图片区按顺序上传 `detail-images/` 里的 `01-overview` → `02-panel-params` → `03-panel-menu`（每张之间可加一句图注，如「整体界面 · 中文菜单与工具栏」）。

### 必填栏位提醒
- **标题**：从「上架文案.md」第一节选一个。
- **类目 / 属性**：按店铺后台实际可用的虚拟商品 / 软件类目选。
- **价格**：未替你填，请按店铺定价填（可参考文案里的建议区间）。
- **购买须知 / FAQ**：文案第六、七节已备好，直接复制。

## 数字虚拟商品交付建议

- 拍下自动发货：发安装包 `SpeedTreeChineseInstaller.exe`（在 `SpeedTreeChinese\dist\`）＋本说明。
- 文案里「九、交付方式建议」也写了网盘 / 自动发货两种方式。

> 提示：本粘贴包里的图片均为实机汉化截图，最好自行核对与当前交付版本是否一致，避免「图对不上货」。
