# 2026-09-28 代码与发布审核

审查自有 Hook/字体布局、委托、启动器、快捷键/采集、字典匹配、Qt 兼容检查及安装打包流程；保留此前已有的源码和词条改动。

## 本轮修复

- 删除以 `QPointer` 为有序 set 键的委托登记表。对象销毁后键变空会破坏排序；宿主替换委托后旧登记也阻止重新安装。现在直接判断当前委托类型，重复安装幂等，宿主自定义委托仍保留。
- 归一化词条冲突不再由 unordered_map 的遍历顺序决定。不同源拼写的精确翻译保留，仅冲突的模糊回退不作猜测。
- 归一化缓存改为线程独立、最多 4096 条，词典构建后清空预热垃圾；达到容量后允许继续缓存新出现的界面文字。语言开关使用原子状态。
- 菜单/顶层窗口语言切换使用弱指针快照，布局回调后重新确认控件存活。
- 启动器按 `LoadLibraryW` 的真实归属模块计算远端地址，支持 Windows 将导出转发到 KernelBase 的情况。
- DLL 路径构造移出 DllMain；工作线程创建失败能返回注入失败。已安装 Hook 固定到进程结束，防止提前卸载。
- 构建必须成功生成 Qt5、Qt6 两套引擎：缺少 Qt5 SDK、Qt5 编译失败、词典复制失败均立即停止，避免继续打包旧文件。
- 删除未使用的 QtWidgets 模块常量；字体测量 ABI 注释采用项目中性说明。

保留所有 QWidget 字体宽度、尺寸、边界、省略、横竖标签页和切换布局 Hook；没有改写源 text/model、宿主 tr() 或工程数据。
